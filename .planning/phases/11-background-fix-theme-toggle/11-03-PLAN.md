    margins at wide viewports. It MUST be the Var `DashboardState.page_bg`, never a static
    hex and never an `assets/global.css` rule — a stylesheet cannot read backend state, and
    a static hex would be immediately wrong in dark mode (11-RESEARCH.md Pitfall 4).
