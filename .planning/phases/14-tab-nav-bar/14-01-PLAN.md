## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Tampering | `set_active_section(value)` | accept | Value is only compared against literals in render-time conditionals; an unrecognized value renders no section (harmless blank), never reaches SQL, the filesystem, or `eval`. No DB or file path is derived from it. |
| T-14-02 | Denial of Service | tab-switch handler | mitigate | Handler performs no I/O and no DB query — rapid tab toggling cannot amplify into repeated `load_rows` calls (asserted by `test_set_active_section_does_not_reload_data`). |
| T-14-SC | Tampering | npm/pip installs | mitigate | Zero new packages this phase (`rx.tabs.*` ships in the already-installed `reflex==0.9.8.post1`); no install task exists, so no legitimacy gate is triggered. |
