<objective>
Build the shared foundation every Phase 2 backtest runner depends on: a SQLite-backed data
loader, the single walk-forward/rolling-origin harness required by D-07, and a unit test that
guarantees the harness never leaks future data into a training window.

Purpose: RESEARCH.md's "Don't Hand-Roll" table names walk-forward slicing as the single most
dangerous bug class in this phase — one off-by-one invalidates every MAPE number produced by
every other plan. Writing it once, tested, before any runner script exists is the whole point
of this wave.
Output: `db_loader.py`, `walk_forward.py`, `test_walk_forward.py`, `ENV.md`.
</objective>

  <name>Task 2: Write leakage tests, then the shared walk-forward harness</name>
  <read_first>
    - .planning/phases/02-model-research-backtesting/02-RESEARCH.md (Pattern 1, Pitfall 1, Pitfall 2)

  <files>backend_research/test_walk_forward.py, backend_research/walk_forward.py</files>
  <behavior>
    - test_no_leakage: with a synthetic Series indexed by 60 monthly Periods and a recording
      fit_fn that captures `train_series.index.max()` at each call, every recorded training
      max must be strictly less than the Period of that origin's first forecast target.
      Assert across ALL origins, not just the first.
    - test_exog_window_alignment: when `exog` is supplied, the DataFrame handed to fit_fn has
      the same length as train_series, and the exog slice passed to `.forecast(exog=...)` has
      length equal to the number of steps requested.
    - test_horizon_records_complete: for min_train=36, horizon=12, step=1 on a 60-point series,
      the returned frame's `horizon_step` values are all within 1..12 and the count of rows for
      horizon_step==1 equals the number of origins.
    - test_actual_matches_series: for every returned row,
      `actual == series.loc[origin_date + horizon_step]` exactly.
    - test_leakage_guard_raises: a deliberately broken fit_fn that reads beyond its training
      window is not required, but the harness's internal assertion must raise `LeakageError`
      when `min_train` is set larger than the series length (degenerate window), rather than
      silently returning an empty frame.
    - test_mape_by_horizon: on hand-built forecast/actual records with known errors,
      mape_by_horizon returns the arithmetic mean absolute percentage error per horizon_step.
  </behavior>
  <action>
    Write `backend_research/test_walk_forward.py` FIRST with the six tests above and confirm they
    fail (module not found), then implement `backend_research/walk_forward.py`.

    Harness implementation, following RESEARCH.md Pattern 1 but with the leakage assertion made
    load-bearing rather than advisory:
    - `walk_forward_backtest(series, exog, fit_fn, min_train=36, horizon=12, step=1, refit_every=1)`.
      Loop `for origin in range(min_train, len(series), step)`. `train_y = series.iloc[:origin]`,
      `train_x = exog.iloc[:origin] if exog is not None else None`.
    - Before every fit, assert `train_y.index.max() < series.index[origin]`; raise `LeakageError`
      (subclass of AssertionError, defined in this module) with the origin index and both dates
      in the message if violated. Also raise LeakageError if `min_train >= len(series)`.
    - `max_h = min(horizon, len(series) - origin)`; skip the origin entirely if max_h < 1.
    - Refit control: refit when `fitted is None or (origin - min_train) % refit_every == 0`;
      store the `refit_every` value used on the returned frame via
      `df.attrs["refit_every"]` so runner scripts can report the cadence per Pitfall 2.
    - Forecast: call `fit_fn(train_y, train_x)` -> results object; call
      `.forecast(steps=max_h, exog=future_x)` when exog is not None else `.forecast(steps=max_h)`.
      Normalise the return with `numpy.asarray(preds).ravel()` so statsmodels Series, numpy
      arrays and plain lists all work identically.
    - Record `origin_date = series.index[origin - 1]` (the last OBSERVED period),
      `horizon_step` 1..max_h, `forecast`, `actual = series.iloc[origin + h - 1]`.
    - Wrap the per-origin fit in try/except; on exception, record the origin in a
      `df.attrs["failed_origins"]` list and continue rather than aborting the whole run —
      GARCH and VAR fits are expected to fail at some early origins.
    - `mape_by_horizon(results_df)`: absolute percentage error grouped by horizon_step, ×100,
      ignoring rows where actual == 0 or is NaN.
    - `single_holdout_mape(series, exog, fit_fn, holdout=12)`: one fixed split at
      `len(series)-holdout`, returning mean MAPE over the holdout — this exists solely so every
      runner can also report the D-07-required comparability number against
      backend_research/REPORT.md's prior figures (HDAN 9.4%, PPAN 10.0%, Diesel-USD 3.4%, FX 0.25%).

    Do not add any model-specific logic to this module — it stays model-agnostic so all five
    runner families share one slicing implementation.
  </action>
