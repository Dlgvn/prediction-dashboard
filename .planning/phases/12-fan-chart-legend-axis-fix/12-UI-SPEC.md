## Chart Layout Contract (the actual scope of this phase)

### Legend position (D-01)

Applies to both `historical_chart_figure` and `forecast_chart_figure`
(`app/app/state.py`) per D-02, even though `historical_chart_figure` currently renders
`showlegend=False` and has no live collision — the layout dict must still be updated in
parallel for consistency, so a future `showlegend=True` flip does not silently reintroduce
the bug this phase fixes.

| Property | Current | New |
|----------|---------|-----|
| `legend.orientation` | `"h"` (forecast only; historical has no `legend` key) | `"h"` (both figures) |
| `legend.y` | unset (defaults ≈1, collides with top margin/vline) | negative, below the plot area — tune in range `-0.2` to `-0.3` during implementation so the legend clears the x-axis title with no excess whitespace |
| `legend.yanchor` | unset | `"top"` |
| `legend.x` | unset | `0.5` |
| `legend.xanchor` | unset | `"center"` |

Legend renders horizontally, centered, below the x-axis title — never top-left/top-right
overlaid on the plot area.

### Margin adjustment

| Property | Current (both figures) | New |
|----------|------------------------|-----|
| `margin` | `dict(l=40, r=16, t=16, b=40)` | `l=40, r=16, t=16` unchanged; `b` increased to accommodate the below-plot legend (tune during implementation — enough that the legend is never clipped or overlapping the x-axis tick labels/title, without introducing dead whitespace) |

### "Forecast start" vline annotation collision check (Claude's Discretion item, carried into contract)

The `add_vline(...)` "Forecast start" annotation in `forecast_chart_figure`
(`annotation_position="top left"`, ~line 757) sits in the *top* of the plot — it did not
collide with the *old* top-anchored legend by accident of position, but must be re-verified
now that the legend has moved to the bottom: confirm no new collision between this
annotation and the plot title/top axis area once the legend vacates the top region. If a
new collision is visually confirmed, adjust `annotation_position`/`annotation_y`
accordingly — do not change the annotation's wording or remove it (out of scope per
12-CONTEXT.md).

### Verification breakpoints

Visually verify legend/axis non-overlap at the desktop, tablet, and mobile breakpoints
already established in Phase 6/7 (VIS-04's "any supported viewport width").
