<planner_decisions>
Two questions 03-RESEARCH.md left open are decided here so the executor does not re-open them.

**P-01 — Diesel-MNT bull/bear combination method (resolves RESEARCH.md Assumption A3).**
Combine at matching scenario edges: `bull = diesel_usd.bull * fx.bull * multiplier`,
`bear = diesel_usd.bear * fx.bear * multiplier`. This is the simple, explainable
approximation recommended by the research and is consistent with D-04's "approximate range
communicated honestly" philosophy. It is NOT a statistically rigorous joint interval — it
treats the two series' errors as compounding in the same direction at the extremes. The
implementation must carry this caveat in its docstring so no reader mistakes it for a
calibrated ~68% band on the product. Variance-propagation-in-quadrature is explicitly
rejected for v1 as unrequired precision.

**P-02 — Return shape (CONTEXT.md left this as the planner's call).**
`forecast_all` returns `dict[str, list[dict]]`:
  keys: `hdan`, `ppan`, `diesel_usd_ton`, `fx_rate`, `diesel_mnt`
  each value: a list of exactly `horizon` row-dicts, ordered h=1..horizon, each shaped
  `{"month": int, "base": float, "bull": float, "bear": float}` where `month` is the
  1-indexed steps-ahead value.
Rationale: row-per-month is directly iterable by a Reflex `rx.foreach` table body (FCST-06)
and directly unzippable into chart traces (VIS-02) without reshaping. The per-series
functions keep their internal columnar `{"base": [...], ...}` shape; `forecast_all` performs
the single columnar-to-row transposition at the boundary.
</planner_decisions>

<interfaces>
Available in `app/app/forecasting.py` from plans 03-01 through 03-03:

  forecast_hdan(history, horizon) -> {"base": [...], "bull": [...], "bear": [...]}
  forecast_ppan_var_system(history, horizon) -> same columnar shape
  forecast_diesel_usd(history, horizon) -> same columnar shape
  forecast_fx(history, horizon) -> same columnar shape
  InsufficientHistoryError(ValueError)
  MAX_HORIZON = 12

Caller contract (Phase 4/5, NOT built in this phase) — record it in the docstring:
  The Reflex state layer reads `PriceRow` rows and the `markup_pct` `AppSetting` value,
  converts them to a plain date-indexed `pd.DataFrame` and a plain `float`, and calls
  `forecast_all(history, horizon, markup_pct)`. This module never opens a session.
</interfaces>
