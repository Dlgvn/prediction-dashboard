Module docstring: states this resolves the prior spike's second named follow-up — whether

independent signal — via a direct measured comparison, not an assumed answer, and that the

Imports: `sys.path.insert(0, str(Path(__file__).resolve().parent.parent))` before

below `data_loader.py`, mirroring `sentiment_data_loader.py`'s existing shim pattern).

Constants:
- `RESULTS_DIR = Path(__file__).resolve().parent.parent / "results"` (flat, existing dir).
- `DEDUP_JSON = RESULTS_DIR / "baltic_an_dedup.json"`
- `DUPLICATE_CORR_THRESHOLD = 0.9`
- `DUPLICATE_MAPE_THRESHOLD = 10.0`

`verdict_from_stats(corr: float, mape_between: float) -> str`:
Returns `"duplicate"` if `corr > DUPLICATE_CORR_THRESHOLD and mape_between < DUPLICATE_MAPE_THRESHOLD`,
else `"independent"`.

`compare_baltic_an() -> dict`:
1. `an = load_an_weekly()[["Baltic AN"]].rename(columns={"Baltic AN": "baltic_an_data_csv"})`
2. `drv = load_weekly_drivers()[["BalticAN_wk"]]`
3. `cmp = pd.merge_asof(an.sort_index(), drv.sort_index(), left_index=True, right_index=True, direction="nearest", tolerance=pd.Timedelta(days=3)).dropna()`
4. `corr = float(cmp["baltic_an_data_csv"].corr(cmp["BalticAN_wk"]))`
5. `mape_between = float(((cmp["baltic_an_data_csv"] - cmp["BalticAN_wk"]).abs() / cmp["baltic_an_data_csv"].abs() * 100).mean())`
6. `verdict = verdict_from_stats(corr, mape_between)`
7. `preferred_column = "AN Data.csv (Baltic AN)" if verdict == "duplicate" else "both (independent signal — consider as separate exogenous predictors)"`
8. Return `{"n": int(len(cmp)), "corr": round(corr, 4), "mean_abs_pct_diff": round(mape_between, 4), "verdict": verdict, "preferred_column": preferred_column, "duplicate_corr_threshold": DUPLICATE_CORR_THRESHOLD, "duplicate_mape_threshold": DUPLICATE_MAPE_THRESHOLD}`.

`main()`: calls `compare_baltic_an()`, prints the dict, `RESULTS_DIR.mkdir(exist_ok=True)`,
writes it to `DEDUP_JSON` via `json.dump(result, f, indent=2)`. No wall-clock timestamp
anywhere in the written JSON (determinism requirement — Task verify runs it twice).

`if __name__ == "__main__": main()`
