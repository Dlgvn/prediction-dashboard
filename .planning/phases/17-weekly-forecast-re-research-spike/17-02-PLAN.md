clean annual cycles at weekly cadence).

hard dependency, not an optional fallback). Returns the parsed dict.

`build_univariate_records(series_name: str, y: pd.Series) -> list[dict]`:
For each of ("SARIMAX", the weekly `_SARIMAXWrapper` with `order` from `select_arima_order`)
and ("ETS-HoltDamped", `_HoltDampedWrapper`): run
`walk_forward_backtest(y, None, fit_fn, min_train=MIN_TRAIN_WEEKLY, horizon=HORIZON_WEEKLY,
step=1, refit_every=1)`, compute `mbh = mape_by_horizon(wf)`, and build a record dict:
`{"series": series_name, "model": ..., "family": "sarimax"|"ets", "driver_variant": "univariate",
"mape_h4": float(mbh.get(4)) if 4 in mbh.index else None,
"mape_h5": float(mbh.get(5)) if 5 in mbh.index else None,
"benchmark_mape": BENCHMARK_MAPE[series_name],
"beats_benchmark_h4": beats_benchmark(mbh.get(4), series_name),
"n_origins": int(wf["origin_date"].nunique()) if len(wf) else 0,
"failed_origins": len(wf.attrs.get("failed_origins", [])), "min_train": MIN_TRAIN_WEEKLY,
"horizon": HORIZON_WEEKLY, "notes": ...}`. For SARIMAX include the selected `(p,d,q)` order in
`notes`; report `failed_origins` explicitly, never silently drop it (Pitfall 4).

`build_exog_sarimax_record(series_name: str, mg: pd.DataFrame, order, dedup_choice: dict) -> dict`:
The Baltic-AN-deduped driver-set variant (CONTEXT.md: "a variant driver set on top of
whichever model(s) it's relevant to," fed into a SARIMAX+exog regression, not a new model
family). Choose the exog column from `mg` based on `dedup_choice["verdict"]`: if
`"duplicate"`, use only `mg["Baltic AN"]` as a single-column exog DataFrame (the AN-side
column, matching `preferred_column`); if `"independent"`, use both `mg[["Baltic AN",
"BalticAN_wk"]]` as a two-column exog DataFrame. Build `y = mg[series_name]`, drop rows with
any NaN across `y`/`exog` first. Run `walk_forward_backtest(y, exog, fit_fn, min_train=MIN_TRAIN_WEEKLY,
horizon=HORIZON_WEEKLY, step=1, refit_every=1)` with `fit_fn = lambda train_y, train_x:
_SARIMAXWrapper(train_y, train_x, order)`. Build the same record shape as above with
`"model": f"SARIMAX{order}+BalticAN(exog, {dedup_choice['verdict']})"`,
`"driver_variant": f"baltic_an_exog_{dedup_choice['verdict']}"`, and a `notes` field stating
which dedup verdict/column choice was used (traceability back to Plan 01).

`run_all() -> list[dict]`:
1. `an = load_an_weekly()`, `mg = merged_weekly()`, `dedup_choice = load_dedup_choice()`.

3. `RESULTS_DIR.mkdir(exist_ok=True)`; `json.dump(records, f, indent=2)` to `RESULTS_JSON`.
4. Return the full records list.
