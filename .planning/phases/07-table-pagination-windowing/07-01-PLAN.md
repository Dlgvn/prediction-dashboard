<objective>
Add the display-only windowing layer to `DashboardState`: a `show_all_history` bool, a
`visible_rows` computed var that returns the most recent 12 rows (or all rows when the
toggle is on), a muted caption var, and a composite toggle handler that also clears
in-progress edit/delete state per D-03.

full-history source of truth for `forecast_results`, `_history_df`,
`historical_chart_figure`, `freshness_chips`, `summary_cards`, and `_export_bytes`.
Output: New state surface plus regression tests, ready for 07-02 to render against.
