# Phase 7 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**This phase adds exactly ONE new UI surface** — a "show all history" toggle for the
Data Entry table. It introduces zero new design tokens, zero new colors, zero new
typography scale steps. Every value below is inherited verbatim from
`06-UI-SPEC.md` / `app/app/theme.py` (Phase 6's locked light design system). Where a
row says "reuse," that means: import the existing constant, do not hardcode a new
literal.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Toggle label (off state, i.e. windowed view active) | "Show all history" — this is the label always shown next to the switch; the switch's checked/unchecked state (not the label text) communicates which mode is active, per standard toggle convention. Do not swap label text based on state (avoids the D-03-noted "flip-flopping label" ambiguity and matches Radix switch conventions). |
| Toggle helper caption (small, muted text below/beside the switch, shown only when collapsed) | "Showing the most recent 12 months." — reuse `MUTED_TEXT` color, `RADIX_SIZE_LABEL` (12px) size, mirrors the existing freshness-chip caption style |
| Toggle helper caption (shown when expanded, i.e. switch is on) | "Showing full history ({N} rows)." — `{N}` bound to `DashboardState.rows.length()`, same muted caption style |
| Empty state (window contains zero rows) | Reuse existing `empty_state()` component verbatim — "No price data yet" / "Add a row to start tracking monthly actuals." Do NOT write new copy for the "12-month window happens to be empty" case; per D-01/discretion, treat it identically to the true-empty-table case since the user's next action (add a row) is the same either way. |
| Primary CTA | "Add row" / "Export to Excel" (existing, unchanged) |
| Destructive confirmation | "Confirm delete?" (existing two-click pattern, unchanged) — note D-03: toggling the switch mid-arm cancels any pending "Confirm delete?" state back to the neutral trash icon, and cancels any in-progress inline cell edit back to display mode. ## Interaction Contract (new — specific to this phase)

This section exists because the only new surface in this phase is interactive, not
purely visual — replaces the template's generic layout section for this phase.

- **Control:** `rx.switch` (Radix switch), NOT a button or link — this is a binary
  state toggle, not a navigation action, so a switch is the correct Radix primitive
  (consistent with using `rx.slider` for horizon rather than buttons).
- **Placement:** Directly below the "Click any cell to edit a month's actuals." helper
  text in `data_entry_section()`, above the table's `rx.box` container, as its own
  `rx.hstack` row: `[rx.switch] [label text] [muted caption]`, `spacing="2"`,
  `align="center"`. This keeps it visually grouped with the table it controls, per
  Phase 6's "Data Entry" region grouping — do not place it in the page header or move
  it away from the table it affects.
- **Wiring:** `checked=DashboardState.show_all_history`,
  `on_change=DashboardState.toggle_show_all_history` — the state handler (not the
  component) is responsible for flipping `show_all_history` AND resetting
  `editing_key`/`pending_delete` per D-03; this UI-SPEC does not prescribe two separate
  event handlers, one composite handler is correct.
- **Table data source:** `data_table()`'s `rx.foreach(DashboardState.rows, ...)` must
  become `rx.foreach(DashboardState.visible_rows, ...)`. The `draft_rows` foreach stays
  unchanged (always visible, per 07-CONTEXT.md discretion note) — no visual distinction
  needed between draft rows and windowed rows; they render in the same table body style
  as today.
- **No loading state needed:** windowing is a synchronous in-memory slice
  (`@rx.var(cache=True)`), not a network fetch — do not add a spinner/skeleton for the
  toggle; this is out of scope and would misrepresent the operation's cost.
- **No new empty/error states beyond the existing `empty_state()` reuse noted above.**
