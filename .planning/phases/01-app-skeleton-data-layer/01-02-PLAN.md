<objective>
Load the real historical price data from `AN Data.csv` and `Diesel Data.csv` into the
`PriceRow` table, collapsing AN's weekly-ish entries to monthly averages and merging both
sources on calendar month.

Purpose: This is the data that Phase 2 backtests against and Phase 3 forecasts from. If the
month collapse or the merge is wrong, every downstream model is trained on wrong numbers —
so the parsing rules are pinned by tests, not by inspection.
Output: `app/app/seed.py` with three tested public functions and a CLI entry point, plus a
populated SQLite table of 78 monthly rows.
</objective>

`AN Data.csv` — 206 data rows, 48 distinct months, 2022-08 through 2026-07.
Every one of the 48 months contains MORE THAN ONE entry, so the collapse rule applies to
all of them. Date format is `M/D/YYYY` (e.g. `7/10/2026`), rows are in DESCENDING date
order. Header strings, verified verbatim (note the leading/trailing spaces and the
trailing empty 11th column produced by a trailing comma):
  'Date' | 'Year' | ' Month ' | ' PPAN ' | ' HDAN ' | ' Baltic AN ' | ' Ammonia '
  | ' Urea ' | ' Natural_gas ' | '  Brent  ' | ''
Numeric cells are space-padded, e.g. ` 463.56 `.

`Diesel Data.csv` — 77 non-blank data rows, 2020-02 through 2026-06, one row per month,
ASCENDING order, PLUS ONE TRAILING ALL-BLANK ROW (`,,,,...`) that must be dropped.
Date format is `YYYY-MM`. Header strings, verified verbatim — the three that matter:
  'Import_Volume_Price_per_ton_USD'  -> diesel_usd_ton   (e.g. ` 638.50 `)
  'FX_rate'                          -> fx_rate          (e.g. `" 2,756.95 "` — quoted, comma thousands separator)
  'URALS_Crude _Oil_(USD/BBL)'       -> urals            (NOTE the stray space after "Crude"; e.g. ` 48.86 `)
Do NOT use 'Total_Import_Value_USD_Per_Ton' for diesel_usd_ton — despite its name that
column holds whole-import totals (~106,745,260), not a per-ton price.

Column mapping produced by `parse_an_data`:
  ' PPAN ' -> ppan | ' HDAN ' -> hdan | ' Baltic AN ' -> baltic_an | ' Ammonia ' -> ammonia
  ' Urea ' -> urea | ' Natural_gas ' -> natural_gas | '  Brent  ' -> brent
'Year' and ' Month ' are redundant with 'Date' — ignore them.

Public function signatures:
  parse_an_data(path) -> pd.DataFrame      # columns: date (datetime64), hdan, ppan, baltic_an, ammonia, urea, natural_gas, brent
  parse_diesel_data(path) -> pd.DataFrame  # columns: date (datetime64), diesel_usd_ton, urals, fx_rate
  seed_database(an_data_path, diesel_data_path) -> int   # returns number of rows written/updated

Expected merge outcome, precomputed from the real files:
  union of months = 78, spanning 2020-02 through 2026-07 with NO gaps
  months 2020-02..2022-07 (30 months): AN-family columns all NULL
  month 2026-07 (1 month): diesel_usd_ton, urals, fx_rate all NULL
  months 2022-08..2026-06 (47 months): fully populated

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CSV files on disk → seed script | Semi-trusted: files are user-supplied exports with messy, inconsistent headers and quoted numerics |
| seed script → SQLite | Writes via SQLModel ORM, no raw SQL string interpolation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Tampering | `seed_database` re-run | mitigate | Upsert-by-date against the D-02 unique constraint; idempotency proven by a double-run test rather than assumed |
| T-01-06 | Tampering | pandas NaN written as non-NULL | mitigate | Explicit NaN→None conversion before ORM assignment, asserted by a round-trip-yields-None test |
| T-01-07 | Tampering | Wrong source column silently used | mitigate | `Total_Import_Value_USD_Per_Ton` grep gate returns 0; expected-value assertions on real data (urea==511.50) catch a wrong-column mapping |
| T-01-08 | Elevation of privilege | SQL injection via CSV cell contents | mitigate | All writes go through SQLModel parameterized ORM calls; no f-string SQL anywhere in seed.py |
| T-01-09 | Repudiation | Silent partial seed | mitigate | `seed_database` returns a written-row count and Task 3 asserts the exact expected total of 78 |
