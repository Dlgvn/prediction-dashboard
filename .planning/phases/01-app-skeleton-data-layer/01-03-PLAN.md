<interfaces>
<!-- Contracts this plan creates. Phase 4 extends these — keep the names stable. -->

app/app/state.py:
  class DashboardState(rx.State)
      rows: list[PriceRow] = []
      load_rows(self)   # opens rx.session(), selects all PriceRow ordered by date ascending, ASSIGNS to self.rows

app/app/app.py:
  data_table() -> rx.Component   # read-only rx.table over DashboardState.rows
  index() -> rx.Component        # page shell, mounts data_table, triggers load_rows on mount

Column display order (matches the ROADMAP success-criterion-3 field list):
  Date | HDAN | PPAN | Baltic AN | Ammonia | Urea | Natural Gas | Brent | Diesel USD/t | Urals | FX Rate
mapped to PriceRow attributes:
  date | hdan | ppan | baltic_an | ammonia | urea | natural_gas | brent | diesel_usd_ton | urals | fx_rate

Data the table will render (seeded by plan 01-02, exact):
  78 rows, 2020-02-01 through 2026-07-01
  30 rows (2020-02..2022-07) have blank HDAN/PPAN/Baltic AN/Ammonia/Urea/Natural Gas/Brent
  1 row (2026-07) has blank Diesel USD/t, Urals, FX Rate

Architectural boundary (ARCHITECTURE.md Anti-Pattern 2, binding):
  Component functions MUST NOT call rx.session() or query the DB. Only DashboardState
  methods open sessions. Components read DashboardState vars and wire events.
</interfaces>

| DashboardState → SQLite | ORM select only; no write path exists in this phase |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-10 | Tampering | UI layer bypassing the state boundary | mitigate | Grep gate asserts zero rx.session occurrences in app/app/app.py; DB access confined to DashboardState per ARCHITECTURE.md Anti-Pattern 2 |
| T-01-11 | Information disclosure | Reflex dev server exposure | accept | Localhost bind, single local user per PROJECT.md; no auth needed and none in scope |
| T-01-12 | Tampering | Unintended write path reaching the DB | mitigate | No write handlers exist in state.py this phase; grep gate asserts no add_row/delete_row |
| T-01-13 | Denial of service | Unbounded row rendering | accept | 78 rows by 11 columns at monthly cadence; scrollable container is sufficient, pagination is unwarranted at this scale |
| T-01-14 | Elevation of privilege | XSS via rendered cell values | mitigate | Values are numerics and ISO date strings from a controlled seed, rendered through Reflex Vars which escape by default; no dangerouslySetInnerHTML equivalent used |
