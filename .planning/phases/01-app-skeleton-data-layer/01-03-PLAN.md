   1. Date          -> date

  10. NG UK         -> natural_gas_uk

  13. Corn China    -> corn_china
  14. Diesel USD/t  -> diesel_usd_ton
  15. Urals         -> urals
  16. FX Rate       -> fx_rate
  17. Brent         -> brent

  Rows before 2022-08 have blank HDAN and PPAN (116 such rows total)
  Rows before 2017-03 have blank Urea Black Sea (50 such rows total)
  Rows before 2016-01 have blank Urea China (37 such rows total)
  The 2013-01-01 first row has ONLY Ammonia populated — every other numeric cell is blank

Architectural boundary (ARCHITECTURE.md Anti-Pattern 2, binding):
  Component functions MUST NOT call rx.session() or query the DB. Only DashboardState
  methods open sessions. Components read DashboardState vars and wire events.
