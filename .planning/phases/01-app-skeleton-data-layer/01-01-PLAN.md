<objective>
Scaffold the Reflex application in `app/` and define the SQLite schema that every later
phase reads from: a wide monthly price table plus a global settings table.

Purpose: This is the foundation phase's foundation. Phase 2 backtests against this schema,
Phase 3 forecasts from it, Phase 4 turns its read path into an editable one. Getting the
schema shape (wide, unique-date, nullable columns) right here avoids a migration later.
Output: A runnable Reflex app skeleton, `PriceRow` + `AppSetting` models, an initialized
SQLite database, and passing schema tests.
</objective>

PriceRow(rx.Model, table=True) fields, in this order:
  date            str, UNIQUE + indexed, stored as ISO month-start "YYYY-MM-01"
  hdan            Optional[float] = None
  ppan            Optional[float] = None

  urea            Optional[float] = None

  brent           Optional[float] = None

  urals           Optional[float] = None
  fx_rate         Optional[float] = None

AppSetting(rx.Model, table=True) fields:
  key             str, UNIQUE + indexed
  value           float
