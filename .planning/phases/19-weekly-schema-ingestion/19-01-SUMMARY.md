- **Assessment:** Functionally equivalent — uniqueness on `date` is still enforced (verified by duplicate-insert test), no application code references the index by name (SQLAlchemy/SQLModel queries operate on column names, not index identifiers). No further action taken; noted here for traceability since it's a real (if cosmetic) schema-object change caused by this plan's migration, even though `PriceRow`'s columns and data are untouched as required.
