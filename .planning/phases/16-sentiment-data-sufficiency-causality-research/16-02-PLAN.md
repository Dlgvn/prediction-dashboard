From backend_research/causality_screen.py (UNCHANGED this phase, imported only):
- `MIN_GRANGER_N = 24`
- `granger_ftest(y, predictor, lag) -> tuple[float, float, int]` — internally builds
  `DataFrame({"y": y, "y_lag1": y.shift(1), "x_lag": predictor.shift(lag)}).dropna()`, fits
  two `sm.OLS` models, returns `(F, p, n)` where `n == len(that dropna'd frame)`. The
  `.shift(lag)` is POSITIONAL, so the predictor passed in must already be aligned onto the
  target's dense monthly index or the lag is not a calendar lag.
- `_tier(p, n) -> str` — `"ns"` if `n < MIN_GRANGER_N`, else `"p05"` if `p < 0.05`, else
  `"p10"` if `p < 0.10`, else `"ns"`.
- Record shape written by `run_granger_sweep()`:
  `{"target", "predictor", "lag", "F", "p", "n", "tier"}` plus
  `"note": "insufficient overlap"` with `F`/`p` set to `None` on the skip branch.
- `RESULTS_DIR = Path(__file__).resolve().parent / "results"` — i.e. `backend_research/results/`,
  flat; 17 JSON files already live there side by side.
- `shortlist_for()` dedupes to one best (lowest-p) lag per predictor via a `by_predictor` dict,
  skipping records whose `p` is `None`. That is the D-02 precedent to mirror.

From backend_research/db_loader.py (UNCHANGED this phase, imported only):
- `TARGETS = ["hdan", "ppan", "diesel_usd_ton", "fx_rate"]` — exactly the four D-04 series;
  `diesel_mnt` is deliberately absent (derived series).
- `load_price_history() -> pd.DataFrame` — monthly `PeriodIndex(freq="M")`, ascending, unique.
- `pct_change_frame(df) -> pd.DataFrame` — `(df.pct_change() * 100).iloc[1:]`

From backend_research/sentiment/sentiment_data_loader.py (created by Plan 01):
- `load_sentiment_monthly() -> pd.DataFrame` — monthly `PeriodIndex(freq="M")` frame, columns
  `SENTIMENT_PREDICTORS + ["article_count"]`, ~20 rows against today's archive.
- `merge_lagged(y, x, lag) -> pd.DataFrame` — columns `y`, `y_lag1`, `x_lag`; reindexes `x`
  onto `y.index` before shifting; raises `walk_forward.LeakageError` on `lag < 1` or a
  non-monthly index. `len(result)` equals the exact `n` `granger_ftest` computes internally.
- `SENTIMENT_PREDICTORS = ["weighted_compound", "sent_ema3", "sent_ema10", "sent_momentum",
  "vix_regime_code"]` — the D-08 set, with D-09's exclusions already enforced there.

   no cross-target case here.

   load-bearing: `granger_ftest` shifts positionally, and the sentiment index is gappy
   (20 months scattered across 2020-2026), so only a series already projected onto the
   target's dense monthly index makes `shift(lag)` a calendar lag. Add a comment saying so.
4. `frame = merge_lagged(y, x_on_y, lag)` and `n_overlap = len(frame)` — Plan 01's helper is

  `None`, mirroring `shortlist_for()`'s `by_predictor` loop. D-02: a predictor qualifies at
  its best lag; do not require agreement across lags. D-03: apply no sign or direction

- `verdict` = `"go"` if `qualifying` is non-empty, else `"no-go"`.

  with their best lags and p-values.
- Return `{"target", "label": SERIES_LABELS[target], "verdict", "max_effective_n", "reason",
  "qualifying"}`.
