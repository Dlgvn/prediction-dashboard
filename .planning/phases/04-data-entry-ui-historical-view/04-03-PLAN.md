<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rendered component -> event handler | Component props carry row identity (`row.date`) back into handlers; identity must come from the rendered Var, not a precomputed index |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-09 | Tampering | _delete_cell / _editable_cell row identity | mitigate | Row identity is the Var `row.date` resolved inside the `rx.foreach` callback, so a click always targets the clicked row (RESEARCH Pitfall 2); handlers additionally re-fetch by date and no-op when the row is absent |
| T-04-10 | Elevation of Privilege | add_row_button disabled state | mitigate | The disabled prop is a UI affordance only; `add_row` in state.py independently no-ops when a draft exists, so a bypassed client control changes nothing |
| T-04-11 | Information Disclosure | rendered table | accept | Single-user local app with no authentication scope per PROJECT.md; all displayed data is the user's own |
</threat_model>
