Add two module-level functions to `app.py`, placed immediately above `forecast_section()` so file order mirrors page order: a private `_summary_card(card: rx.Var) -> rx.Component` and a public `forecast_summary_cards() -> rx.Component`.

`_summary_card` renders an `rx.box` styled from theme tokens: `background=SURFACE`, `border=CARD_BORDER`, `border_radius=CARD_RADIUS`, `padding=CARD_PADDING`, `min_width="200px"`, `flex="1 1 200px"`. Inside it an `rx.vstack` with `spacing="2"` and `align="start"` containing, top to bottom:
1. Eyebrow label: `rx.text(card["label"], ...)` at `size=RADIX_SIZE_LABEL`, `color_scheme="gray"`, `text_transform="uppercase"`, `font_weight=FONT_WEIGHT_SEMIBOLD` — matching the existing freshness-chip label treatment.
2. An `rx.cond` on `card["has_data"] == "yes"`. The true branch is the big number: `rx.text(card["base"], font_size=FONT_SIZE_DISPLAY, font_weight=FONT_WEIGHT_SEMIBOLD, line_height="1.2")`. The false branch is `rx.text(card["no_data_text"], size=RADIX_SIZE_BODY, color=MUTED_TEXT)` — this single cond covers the whole numeric block, so the range and direction rows only appear on the true branch.
3. Expected-range line (true branch only): an `rx.hstack` of `rx.text(card["range_label"] + ":", ...)` in muted label styling and `rx.text(card["range_text"], size=RADIX_SIZE_BODY)`. Do not hardcode the words — the copy comes from state so D-13 wording lives in one place.
4. Direction line (true branch only): an `rx.hstack` with `spacing="1"` containing `rx.text(card["arrow"] + " " + card["delta_text"], ...)` colored by `rx.cond(card["direction"] == "up", UP, rx.cond(card["direction"] == "down", DOWN, MUTED_TEXT))` with `font_weight=FONT_WEIGHT_SEMIBOLD`, followed by `rx.text(card["caption"], size=RADIX_SIZE_LABEL, color=MUTED_TEXT)`. The arrow glyph carries the meaning; color is supporting only (D-11).

Add `aria_label` on the card box combining label, base value, and direction text so a screen reader announces the card as one unit rather than four loose strings.

`forecast_summary_cards()` returns an `rx.vstack` of an `rx.heading("Forecast Summary", size=RADIX_SIZE_HEADING)` and an `rx.hstack(rx.foreach(DashboardState.summary_cards, _summary_card), spacing="3", wrap="wrap", width="100%", align="stretch")`. Use `wrap="wrap"` so four cards reflow on narrow viewports without a media query.

Add the `from app.theme import ...` import at the top of `app.py` alongside the existing `from app.state import ...` block.

Extend `app/tests/test_app_components.py` (following its existing `isinstance(component, rx.Component)` compile-smoke style, which catches invalid Var operations without a browser): assert `forecast_summary_cards()` compiles; assert the rendered string of `forecast_summary_cards()` references `summary_cards`; assert the rendered output contains both the up and down arrow glyphs and both `UP`/`DOWN` hex values (proving the cond branches wired); assert it contains neither "confidence" nor "guaranteed".
