Each dict carries keys: `series_key`, `label` (from `FORECAST_SERIES_LABELS`), `has_data` (`"yes"`/`"no"`), `base` (horizon-end base value formatted with `NUMBER_FORMAT`, or `""`), `range_text` (formatted as `"{lower} – {upper}"` using an EN DASH with spaces, lower = bear, upper = bull; `""` when no data), `range_label` (the literal `"Expected range"` per D-13), `arrow` (`ARROW_UP`/`ARROW_DOWN`/`ARROW_FLAT` from `app.theme`), `direction` (`"up"`/`"down"`/`"flat"` — a string discriminator so `app.py` picks the color with `rx.cond`, never a raw hex in state), `delta_text` (e.g. `"4.2%"` or `""`), `caption` (the literal `"vs. latest actual"` per UI-SPEC), and `no_data_text` (the literal `"Add pricing data to see a forecast"` per UI-SPEC).

Derivation rules, in order:
1. Read `self.forecast_results` — do NOT call `forecast_all` (single-call-site guard). Take `series = results.get(key, [])`; if empty, emit the no-data card (`has_data="no"`, empty numerics, `arrow=ARROW_FLAT`, `direction="flat"`).
2. Horizon-end value per D-10/D-12 is the LAST entry of `series` (the entry whose `month` equals the current `horizon_months`); guard by indexing `series[-1]` rather than assuming length equals `horizon_months`.
3. Latest actual per D-11: scan `self.rows` for the last non-None value of the series attribute; for `diesel_mnt` compute `diesel_usd_ton * fx_rate * (1 + self.markup_pct / 100.0)` from the last row where BOTH inputs are non-None, exactly matching `forecast_chart_figure`'s convention.
4. Direction: `up` when horizon-end base exceeds latest actual, `down` when below, `flat` when equal, when there is no latest actual, or when latest actual is zero (avoids a ZeroDivisionError on the percent delta). `delta_text` is the absolute percent change to one decimal place with a trailing `%`; empty string in the flat/no-actual case.
5. Never emit the words "confidence interval" or "guaranteed" anywhere in this var (D-13).
