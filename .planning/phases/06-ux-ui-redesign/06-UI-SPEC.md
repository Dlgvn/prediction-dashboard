# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — Reflex (Python) compiles to Radix Themes under the hood; there is no `components.json`/shadcn CLI workflow in this stack. All styling is expressed as Python kwargs on `rx.*` components and Plotly figure-builder code in `state.py`. |
| Preset | not applicable |
| Component library | Radix Themes (via Reflex's built-in component set: `rx.table`, `rx.select`, `rx.slider`, `rx.button`, `rx.box`, `rx.vstack`/`rx.hstack`, etc.) |
| Icon library | `rx.icon` (Lucide icon set, already in use — e.g. `"trash-2"`, `"download"` in app.py) |
| Font | Radix Themes default system font stack (Inter fallback) — no custom font import in this phase; introducing a new webfont is out of scope for a presentational-only redesign. |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip internal padding |
| sm | 8px | Compact stacks (hstack/vstack `spacing="2"`), card internal gaps |
| md | 16px | Default element spacing, card padding, table cell padding |
| lg | 24px | Section padding (`padding="1.5rem"` already used in `historical_chart()`/`forecast_chart()` boxes — keep as-is) |
| xl | 32px | Gaps between major page sections (summary cards → fan chart → table → historical block) |
| 2xl | 48px | Space above/below the bottom data-entry block, marking it as a distinct "maintenance" zone per D-03 |
| 3xl | 64px | Not used this phase (single-column layout, no page-level multi-region spacing needed) |

Exceptions: icon-only delete button (`_delete_cell`'s `rx.icon_button`) keeps its existing `min_width="32px"`/`min_height="32px"` — below the 44px touch-target ideal but acceptable since this is a desktop-first single-user internal tool (no mobile requirement in REQUIREMENTS.md/CONTEXT.md), and changing this hit target is out of scope (D-08/D-09 restrict changes to chart figures + page layout, not the existing delete-cell control).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 600 (semibold) | 1.4 — used for card eyebrow labels ("HDAN", "Series", freshness-chip labels), uppercase, `color_scheme="gray"` |
| Heading | 20px | 600 (semibold) | 1.2 — section headings ("Forecast", "Forecast — base / bull / bear", new "Historical" / "Data Entry" headings) |
| Display | 28px | 600 (semibold) | 1.2 — the big number on each forecast summary card (the base forecast value); page title ("Prediction Dashboard") may stay at its current larger `size="9"` Radix scale step since it's a one-time app-level heading, not part of the repeating card grid |

Exactly 3-4 sizes / 2 weights, per contract: 12 / 14 / 20 / 28px; weights 400 and 600 only. Map Radix `size` props to these targets: `size="1"`≈12px (Label), `size="2"`≈14px (Body — already the app's dominant size), `size="4"`≈20px (Heading), and the new summary-card big number uses an explicit `font_size="28px" font_weight="600"` (no existing Radix step matches 28px cleanly, so declare explicitly on the card component).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FAFAFA` (near-white, Radix `gray.1`/App background) | Page background |
| Secondary (30%) | `#FFFFFF` white with `1px solid #E4E4E7` (Radix `gray.5`) border | Card surfaces: forecast summary cards, chart boxes, table container, freshness chips |
| Accent (10%) | `#3B82F6` (indigo/blue — already used as the fan chart's base-forecast line color and band fill, keep as the single locked accent hex) | Reserved strictly for: (1) fan chart base-forecast line + band fill (already implemented, keep), (2) horizon slider active track/thumb, (3) primary CTA buttons (Export to Excel, Add row), (4) selected/active state on the Series `rx.select` control, (5) the "Forecast" section heading's accent underline/icon if added. Do NOT use accent for card borders, table headers, or body text. |
| Destructive | `#DC2626` (red, Radix `red.9` — matches existing `color_scheme="red"` on delete button/confirm) | Reserved strictly for: delete-row confirm button, delete-row icon button, validation error text (`edit_error`), export failure message text. |

Second semantic pairing (not a third accent color, but a functional pair used only for forecast direction, per D-05/D-11):
- Up: `#16A34A` (green, Radix `green.9`) + `↑` glyph — direction text, never color alone
- Down: `#DC2626` (same red as destructive, reused — Radix `red.9`) + `↓` glyph

Accent reserved for: fan chart base line/band, horizon slider, primary buttons (Export to Excel, Add row), active Series select state. Never used for card borders, headings, or table chrome — those stay neutral gray per D-05/D-06 (no navy header, no dark mode).

## Layout & Page Order (locked, per CONTEXT.md D-01..D-04)

1. Header (`rx.heading("Prediction Dashboard")` + subtitle text — existing, unchanged)
2. **NEW:** Forecast summary cards row — 4 cards (HDAN, PPAN, Diesel-MNT, FX), horizontal `rx.hstack` with `wrap="wrap"`, each card: series label (12px label style) → big base-forecast number (28px display style, formatted `1,234.56`) → "Expected range: {lower} – {upper}" (14px body) → direction badge (`↑`/`↓` + % + "vs. latest actual", green/red per D-11)

4. `forecast_chart()` (existing fan chart, restyled in place per D-08 — no structural change)
5. `forecast_table()` (existing, unchanged)
6. `freshness_chips_row()` + `export_button()` (existing, unchanged — reordered to sit after the table per D-04)
7. **NEW** "Historical" heading + `historical_chart()` (moved from top to here, unchanged internals)
8. **NEW** "Data Entry" heading + `data_table()` + `add_row_button()` (moved from top to bottom, unchanged internals)

Component naming convention for the new card row: `forecast_summary_cards()` in `app.py`, reading a new computed var (e.g. `DashboardState.summary_cards`) that derives from the existing `forecast_results` var — no new state beyond a `@rx.var` per D-12 (horizon-reactive via the existing shared `horizon_months`).

## Chart Restyle Notes (D-08/D-09 — presentational only, no data-flow changes)

- `forecast_chart_figure`: keep existing historical/base/band trace structure; ADD a vertical line/annotation marking "Forecast start" at `last_hist_date`; keep historical line solid gray (`#697177`), keep base forecast line accent blue (`#3B82F6`) but consider dash style differentiation is unnecessary since color already distinguishes them — however, per D-08, add a dashed historical→forecast transition style if the checker flags ambiguity. Improve hover template to show formatted numbers (`%{y:,.2f}`) instead of default float display. Axis labels already present — keep, ensure tick format uses thousands separators.
- `historical_chart_figure`: apply the same hover-format and axis-label polish; no structural change (single-series line + markers, gray `#697177`).
- Both figures should use `margin=dict(l=40, r=16, t=16, b=40)` (already the pattern) and a light `plot_bgcolor`/`paper_bgcolor` of `#FFFFFF` or `transparent` to match the card/surface color, not Plotly's default gray-blue theme.
