# Milestone v2.0: News/Sentiment Scenarios & Weekly Forecast Research

**Status:** ✅ SHIPPED 2026-09-01
**Phases:** 16-17 (Phase 18 dropped — gated on Phase 16 returning "go", which it did not)
**Total Plans:** 4

## Overview

Two independent, research-only spikes with no UI or `app/` code shipped this milestone,
regardless of outcome:

1. Whether a news/sentiment-driven adjustment to the bull/bear scenario bands is viable
   against the app's real HDAN/PPAN/Diesel-USD/FX series (Phase 16).
2. Whether weekly-cadence HDAN/PPAN forecasting can clear a new backtest bar with genuinely
   new variables/model families, compared against the prior spike's no-go benchmark
   (Phase 17).

Phase 18 (sentiment-adjusted scenario UI) would only be built if Phase 16 returned a "go" —
it returned "no-go", so Phase 18 was correctly dropped from the milestone rather than built
in a degraded form.

## Phases

### Phase 16: Sentiment Data Sufficiency & Causality Research

**Goal**: Determine, via a rigorous causality/correlation backtest run against the app's
actual HDAN/PPAN/Diesel-USD/FX series (not equities), whether a sentiment-driven scenario
adjustment is viable enough to build — with a documented, frozen go/no-go result as the
deliverable. A "no-go" is a complete, valid outcome for this phase, not a failure to fix.
**Depends on**: Nothing (independent research phase; reuses Phase 2's `walk_forward.py`/
causality-screen discipline)
**Requirements**: SENT-01, SENT-02
**Plans**: 2 plans

Plans:

- [x] 16-01-PLAN.md — Monthly sentiment predictor loader (UTC+8-corrected) and
      leakage-guarded merge helper with tests (wave 1)
- [x] 16-02-PLAN.md — Run the causality screen against the real HDAN/PPAN/Diesel-USD/FX
      series, freeze `results/sentiment_causality_screen.json` and generate
      `REPORT-SENTIMENT.md` (wave 2)

**Result**: **No-go.** All four series (HDAN, PPAN, Diesel-USD, FX rate) — effective
monthly overlap between real price history and the sentiment archive (14/14/19/20) never
reaches `MIN_GRANGER_N=24`. Verdict is a genuinely computed branch, proven non-hardwired by
tests that flip synthetic p05/p10 records to "go".

### Phase 17: Weekly Forecast Re-Research Spike

**Goal**: Re-research weekly-cadence HDAN/PPAN forecasting with genuinely new candidate
variables and/or model families (not a rerun of the prior weekly-VAR-on-Baltic-AN/Ammonia/
Urea/Natural-Gas no-go), and produce a documented go/no-go comparison against the prior
spike's exact benchmark (9.49%/10.08% monthly MAPE). No weekly UI ships in this milestone
regardless of the outcome — this phase is research-only.
**Depends on**: Nothing (independent of Phase 16; reuses the existing walk-forward,
horizon-matched backtest methodology)
**Requirements**: WKLY-01, WKLY-02
**Plans**: 2 plans

Plans:

- [x] 17-01-PLAN.md — Patch `data_loader.py` to repo-root-relative paths and resolve the
      Baltic-AN dedup question with a frozen verdict (wave 1)
- [x] 17-02-PLAN.md — Run weekly-cadence SARIMAX/ExponentialSmoothing candidates via the
      shared walk-forward harness, freeze `results/weekly_sarimax_ets.json` and generate
      `REPORT-WEEKLY.md` with the go/no-go comparison against the 9.49%/10.08% benchmark
      (wave 2)

**Result**: **Go.** All 6 weekly-cadence candidates (HDAN/PPAN × SARIMAX, ETS-HoltDamped,
SARIMAX+BalticAN-exog) beat the fixed monthly VAR benchmark at the 4-week horizon — best
HDAN 7.25%, best PPAN 6.96% (SARIMAX+exog), vs. the 9.49%/10.08% benchmark. Baltic-AN dedup
resolved: the two source columns are a duplicate signal (corr=0.983). No weekly UI ships
this milestone despite the favorable verdict, per explicit scope and REQUIREMENTS.md's
v2.1+ Deferred section.

### Phase 18: Sentiment-Adjusted Scenario UI (conditional on Phase 16 go) — DROPPED

**Goal**: If Phase 16 returned a go, surface a sentiment-adjusted bull/bear band on the
existing fan chart with honest provenance, staleness/coverage warnings, and a toggle.
**Requirements**: SENT-03..08
**Status**: Never built. Phase 16 returned no-go, and SENT-03..08 are explicitly gated in

## Milestone Summary

**Key Decisions:**

- Both phases reuse Phase 2's `walk_forward.py` harness and `causality_screen.py`'s
  `granger_ftest`/`_tier`/`MIN_GRANGER_N` by import, never redefinition — a structural
  guarantee that the sentiment/weekly bars are provably identical to every other
  predictor's bar.
- Phase 18 is gated strictly on Phase 16's outcome and dropped (not degraded) on no-go —
  decided up front in the roadmap, honored exactly as specified.
- No `VERIFICATION.md` produced per-phase (`workflow.verifier_enabled: false` in project
  config, a deliberate setting) — verified instead via a milestone-level audit
  (`.planning/v2.0-MILESTONE-AUDIT.md`) cross-referencing REQUIREMENTS.md, SUMMARY
  frontmatter, and the frozen JSON/report artifacts.
- Deterministic-report discipline established in Phase 16 (`REPORT-SENTIMENT.md`, no
  wall-clock content, byte-identical across reruns) was carried forward unchanged into
  Phase 17's `REPORT-WEEKLY.md`.

**Issues Resolved:**

- `backend_research/data_loader.py` had hardcoded macOS-absolute CSV paths that would have
  raised `FileNotFoundError` on any other machine (discovered live during Phase 17 research
  on a fresh Windows checkout) — fixed to repo-root-relative paths mirroring `db_loader.py`'s
  existing pattern.
- Windows' default `open()` encoding (system codepage, not UTF-8) was corrupting em-dash
  characters in `REPORT-SENTIMENT.md` on first generation — fixed with explicit
  `encoding="utf-8"` on all report/JSON writes, carried forward into Phase 17.
- The local development machine had neither Node.js nor Python installed (only Windows
  Store stub shims) — resolved by installing Node.js LTS and Python 3.12 via `winget`, then
  installing the exact research-environment pins from `backend_research/ENV.md` (pandas
  2.2.3, statsmodels 0.14.6, scikit-learn 1.7.2, arch 8.0.0) system-wide.

**Issues Deferred:**

- `16-02-SUMMARY.md` is missing the `requirements-completed: [SENT-01, SENT-02]` frontmatter
  field that `17-02-SUMMARY.md` has — a documentation-consistency nit flagged in the
  milestone audit, not worth its own gap-closure phase.
- Weekly-cadence UI is deferred to its own future milestone regardless of Phase 17's "go"
  result, per REQUIREMENTS.md's v2.1+ Deferred section.

**Technical Debt Incurred:**

- None identified beyond the documentation nit above — both phases are additive-only
  research scripts under `backend_research/`, zero `app/` changes, zero new production
  dependencies.
