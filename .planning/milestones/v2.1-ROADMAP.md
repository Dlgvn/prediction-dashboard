# Milestone v2.1: Weekly Forecast UI

**Status:** ✅ SHIPPED 2026-09-02
**Phases:** 19-22
**Total Plans:** 8

## Overview

Ships genuinely weekly-cadence forecasting for HDAN, PPAN, and FX rate on the dashboard —
the first user-facing feature built on the research validated in v2.0's Phase 17 (weekly
HDAN/PPAN, a "go") plus a new weekly FX backtest against a freshly-identified data source
(`FX Data.csv`'s Weekly column). Diesel-USD and derived Diesel-MNT have no weekly source
data and are honestly marked "monthly only" in Weekly mode — shown grayed-out with real
monthly numbers, never hidden or faked. Forecast-viewing only; the existing monthly Data
Entry flow is unaffected.

## Milestone Summary

**Key Decisions:**

- Weekly forecasting functions transcribe Phase 17/20's already-frozen, already-backtested
  model constants verbatim — no runtime re-derivation, continuing the project's core "no
  un-backtested model ships" discipline into this milestone.
- Weekly and monthly forecasting logic live side by side in the same `forecasting.py`
  module (not a separate file), sharing low-level helpers (`_arima_forecast_se`,
  `_forecast_predictor`) while keeping `WEEKLY_`-namespaced constants and functions
  structurally distinct.
- `WEEKLY_CAPABLE_SERIES = frozenset({"hdan", "ppan", "fx_rate"})` gates all weekly-mode
  UI branching, so Diesel cards can never accidentally render fabricated weekly data even
  as a bug — the constraint is structural, not just convention.
- A single global Monthly/Weekly toggle (not per-series) drives both the Forecast tab
  chart and Summary cards together, with Monthly as the persistent default.
- Diesel-USD's own summary card was restored (originally excluded in v1's design in favor
  of Diesel-MNT-only) because WKUI-05 requires both series be honestly represented in
  Weekly mode — an integration-checker-confirmed requirement-driven fix, not scope creep.

**Issues Resolved:**

- FX weekly forecasting required a genuinely new weekly data source
  (`FX Data.csv`'s Weekly column, 865 rows, 2010-2026) since no prior weekly FX data
  existed — parsed via positional column slicing to handle the file's three-cadence
  single-CSV layout (Daily/Weekly/Monthly column pairs).
- `HoltWintersResults` (statsmodels) has no `.get_forecast()`/`.se_mean` the way ARIMA
  models do — resolved with a `.simulate()`-based Monte Carlo spread (seeded
  `random_state=0` for determinism), a new pattern not previously used in this codebase.
- Reflex's `rx.segmented_control.root` declares a broader `str | list[str]` event-arg type
  than the app's `set_granularity(value: str)` handler — resolved with a call-site lambda
  cast rather than loosening the handler's locked interface.
- A Phase 21 Wave 1 executor was interrupted mid-run (killed before writing any code) and
  cleanly resumed from a clean git state with no partial-work cleanup needed.

**Issues Deferred:**

- None new this milestone (v2.0's minor `16-02-SUMMARY.md` frontmatter gap remains
  unaddressed, not worth its own fix).

**Technical Debt Incurred:**

- None identified. All phases stayed within their scope boundaries (confirmed via
  commit-level `git show --stat` in the integration audit); zero test regressions across
  429 total tests by the milestone's end.
